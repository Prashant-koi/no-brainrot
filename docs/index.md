# Privacy Policy for No Brainrot

Last updated: January 2026

## Data Collection
No Brainrot does not collect or transmit personal data.

The extension stores usage statistics (time spent on supported websites) locally in the user's browser using Chrome’s storage APIs.

## Data Usage
Stored data is used only to:
- Block short-form content
- Display local usage statistics in the dashboard

## Data Sharing
No data is sold, shared, or transmitted to any third parties.
No external servers are used.

## Permissions
The extension uses site access permissions solely to detect and block short-form content and measure time spent on supported websites.
